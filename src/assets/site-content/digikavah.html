Hackathon Achievement

DIGIkavah v2.0 was awarded 2nd Prize at the HPTU Hackathon 2026 for solving high-stakes scam detection with:

  • 100% Benchmark Accuracy: 75/75 real-world attack vectors classified with zero false positives across Dev and blind Holdout sets.
  • Inviolable Zero-Fetch Safety: Proved mathematically with 0 outbound network requests to submitted scam URLs, protecting users from drive-by downloads or token burns.
  • Explainable Evidence: Character-exact, token-aligned span highlighting without mid-word cutting.
  • Statutory Indian Citizen Protection: Direct 1-click 1930 Cyber Crime Helpline dialing, RBI 72-Hour Zero-Liability emergency timer, and DoT Sanchar Saathi Chakshu reporting scripts.

Core Architecture & Detection Engine

Constructed with Next.js 14 App Router, TypeScript (Strict Mode), and a 4-subsystem weighted fusion matrix:

  • Subsystem A (Psychological Radar): 5-axis manipulation heuristics analyzing urgency, coercion, and TRAI DLT headers.
  • Subsystem B (Zero-Fetch URL Sandbox): Deconstructs malicious URLs purely using string math — Shannon Entropy ($H > 4.2$), Damerau-Levenshtein distance against 28 trusted brands, and Cyrillic homoglyph swaps.
  • Subsystem C (RFC-822 Email Forensics): Zero-network header inspection verifying SPF/DKIM/DMARC status, display-name spoofing, and anchor-text mismatches.
  • Subsystem D (Contextual AI): Google Gemini 2.5 Flash reasoning model with 100% resilient local heuristic fallback.

Multi-Channel Ingestion & Security

  • In-Browser OCR: Client-side Tesseract.js running in a Web Worker with Laplacian variance image quality guards.
  • Client-Side Credential Masking: In-memory Luhn checksum redactor in browser RAM that sanitizes card numbers, Aadhaar, CVVs, and UPI PINs before analysis.
  • 24x7 KavachBot Advisor: Interactive security coach providing bank freezing checklists and incident recovery steps.
