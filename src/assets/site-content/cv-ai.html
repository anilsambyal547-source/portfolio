System Architecture

CV AI is built as a decoupled distributed system:

  • Backend Engine (Python): Powered by Python, asynchronous endpoints, text extraction modules, and structured NLP evaluation pipelines.
  • Frontend Application (TypeScript): A modern interactive dashboard enabling users to inspect extracted criteria, candidate scores, and semantic highlights.

Key Capabilities

  • Automated entity recognition for technical skills, certifications, and experience timelines.
  • Semantic matching against role rubrics rather than basic keyword checks.
  • Structured JSON output generation with validated schema constraints.
