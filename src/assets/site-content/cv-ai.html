System Architecture

CV AI is built as a high-performance decoupled distributed system:

  • Frontend Application: Built with Next.js, TypeScript, Tailwind CSS, Shadcn/UI, Framer Motion, and TanStack Query. Features drag-and-drop candidate pipelines via @dnd-kit and live analytics with Recharts.
  • Backend Engine: Asynchronous FastAPI (Python 3.10+) service utilizing background workers for non-blocking resume indexing and duplicate detection via SHA-256 hashing.
  • AI & LLM Ingestion: Google Gemini Pro via the official SDK for structured entity extraction (experience timelines, skills, credentials).
  • Vector Storage & Semantic Search: ChromaDB with Sentence Transformers (all-MiniLM-L6-v2) enabling intent-based semantic search and hybrid scoring against job rubrics.
  • Security: JWT authentication with Role-Based Access Control (Admin vs. Recruiter) and request rate limiting.

Key Capabilities

  • Automated Extraction: Parses messy multi-column PDFs into validated, structured schema objects.
  • Semantic Vector Search: Finds candidates by conceptual skill matches rather than rigid keyword queries.
  • Interactive Pipeline Board: Seamless candidate stage tracking across Applied, Interview, and Hired states.
