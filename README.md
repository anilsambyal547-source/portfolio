## 🌟 Overview

An industrial, brutalist-inspired interactive personal portfolio featuring real-time physics simulations, fluid page transitions, live project case studies, and a printable CV.

### Key Highlights
- **Interactive Physics Engine**: Matter.js driven draggable badges and gravity-responsive elements.
- **Fluid Single-Page Navigation**: High-performance page transitions powered by **Barba.js** and smooth inertial scrolling with **Lenis**.
- **Responsive Industrial UI**: Crafted with custom monospace typography, pixel accents (`pixelarticons`), and high-contrast brutalist aesthetics.
- **Print-Optimized CV**: Dedicated printable resume at `/cv-printable` styled with native `@media print` directives.

## 🛠 Tech Stack

- **Core**: Vanilla Modern JavaScript (ES6+), HTML5, CSS3
- **Animations & Physics**: [GSAP](https://greensock.com/gsap/) (GreenSock), [Matter.js](https://brm.io/matter-js/), [Lenis Scroll](https://github.com/darkroomengineering/lenis)
- **Routing & State**: [@barba/core](https://barba.js.org/) for SPA transitions
- **Bundler & Build**: [Webpack 5](https://webpack.js.org/), Babel Loader, CSS Loader, PostCSS
- **Icons & Assets**: Pixelarticons, SVG vector graphics

## 💻 Local Development

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- [npm](https://www.npmjs.com/)

### Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/anilsambyal547-source/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:8080](http://localhost:8080) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
   Compiled bundles will be generated in `dist/`.
